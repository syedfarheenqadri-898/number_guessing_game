# Number Guessing Game

## About:
This is a simple Python Number Guessing Game. The computer chooses a random number between 1 and 100, and the player has 5 chances to guess it. After each guess, the program tells the player if the guess is too high or too low.

## Features:
- Random number generation
- 5 guessing attempts
- Hints after every guess
- Input validation
- Win or Game Over message

## How to Run:
1. Open the project in VS Code.
2. Run the Python file.
3. Enter your guesses and enjoy the game.
